The Dreamina Seedance Advanced Creation Rights package is a value-added subscription service for enterprise users of Dreamina Seedance 2.0 and Dreamina Seedance 2.5. It supports yearly and monthly subscriptions, providing larger capacity for private asset libraries, higher API call QPM, and enterprise-level content creation support.

## Prerequisites
- Register a BytePlus account and complete the enterprise verification.
- Complete the Organization real-name authentication by submitting the required proof materials including a photo copy of the corporate registration certificate.
- Agree and comply with: BytePlus Terms of Use for Asset Library; BytePlus Commitment Letter for Uploading Virtual Avatar Assets; BytePlus Real Person Verification H5/API - Usage Rules; BytePlus Platform Customer Code of Conduct and Default Handling Rules.

## Benefits overview
Manage private assets via the Assets API integration; larger private asset library capacity and higher API throughput; access to enterprise-grade content creation support.

## How to subscribe
Go to Model activation > Advanced Creation Rights, select your desired package, complete payment. Usage viewable at Model activation > Advanced Creation Rights afterward.

## Rules
- Effective period: yearly takes effect immediately, expires same date next year; monthly expires same date next month.
- Only one subscription active per BytePlus account at a time.
- Upgrade: flexible, price-difference calculated pro-rata against remaining validity period. Monthly->Yearly and tier upgrades both supported with different proration formulas (see live page for exact formulas if needed).
- Downgrade: NOT supported (Premium->base, or yearly->monthly).
- Unsubscription: once purchased, confirmed, no refund.
- Renewal: yearly up to 1 year at a time, renewable from 30 days before expiry; monthly up to 3 months at a time, remaining + new duration capped at 4 months total.
- Expiration:
  - Grace period (0-15 days after expiry): quota downgraded to Advanced Creation Rights (Entry) limits. If asset/asset-group count exceeds the free 50 limit, new real-human assets cannot be added. Cannot create new asset groups or upload assets via API; existing assets still usable. Upgrade not available during grace period.
  - Resource reclamation (15+ days past expiry): assets can no longer be queried or used. Assets and asset groups created during the paid subscription period are DELETED, unrecoverable. Assets/groups created before the paid period, or within 15 days after expiry, are NOT deleted. Renewal no longer available - a new purchase is required.

## FAQ
Q: Will uploaded assets be deleted after the entitlement expires?
A: After 15 days overdue, assets and asset groups created within the paid subscription period will be deleted, unrecoverable. Back up data in advance.
